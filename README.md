# Medinfar × Salesforce — AI & Agentforce Workshop

Workshop interativo em português.

Abra `index.html` ou `medinfar-trailmap.html` num navegador. As imagens e fontes estão incluídas na página; não é necessária instalação.

Os links externos precisam de Internet e das permissões de acesso correspondentes. O progresso fica guardado apenas no navegador de cada utilizador.

## Publicação

Site estático compatível com GitHub Pages, a partir da raiz do ramo `main`.
